# Changelog

All notable changes to Lagoon will be documented in this file.

## [1.0.0] - 2026-05-21

Initial public release.

### Highlights

- Runtime LoongArch assembler library written in C.
- Mnemonic entry points generated from `loongarch-opcodes`.
- Label binding and backpatch support for branch and PC-relative fixups.
- Single-instruction disassembly and instruction string formatting helpers.
- MIT-licensed source distribution.
